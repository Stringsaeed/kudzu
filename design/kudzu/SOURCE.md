# Source

A read-only copy of the "Kudzu" design system from Claude (https://claude.ai/artifact/TuYZAtTUiPQ6hWy7Uwzcfv), downloaded 2026-11-02.

`project/` is the design system:
- `README.md`: principles, content rules, visual foundations, and notes for building it in SwiftUI
- `tokens.json`: colour, type, space, radius, shadow, size and blur tokens, each with a usage note
- `components/<Name>/README.md`: a usage note for each component
- `components/<Name>/preview.html`, `bundle.css`, `bundle.js`: the HTML reference implementation, which also holds the icon paths
- `assets/Logos/`: the app icon and menu bar icons

Treat the artifact as the source of truth. To refresh this copy, download it again; don't edit it here.
