# Window

The whole app in this system, live: click the sidebar, rows and settings sections. Snippets, stats and settings share one window and one layout.

- Sidebar: glass, Library items, Groups, and Settings pinned to the footer with ⌘,.
- List pane: ListHeader with sort and new-snippet actions, the SearchField, then rows.
- Detail: a floating ToolbarGroup for the selected snippet, the name as a mono title, Triggers, Content, Preview, then Rules and Advanced as disclosures.
