# SettingsRow

One setting: label and optional description on the left, its control on the right. Rows inside a SettingsGroup are split by `line` hairlines.

Consumer provides `label`, optional `description` and `icon`, and the control as children (Toggle, Segmented, Stepper, Select, small Button). Label is `body-strong`; description is `callout` in `ink-muted`, one sentence, no trailing period needed for fragments.
