# SearchField

The search field at the top of the list pane; it filters the list below it, so it lives with the list, not in the window toolbar.

Consumer provides `placeholder`, value handlers, and `shortcut` (defaults to ⌘F; `false` hides the keycap). At rest it is a `surface-sunken` well with no border; focus turns it `surface-raised` with a 2px `vine-ink` edge.
