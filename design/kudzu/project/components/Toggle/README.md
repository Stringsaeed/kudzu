# Toggle

An on/off switch for settings that apply immediately.

Consumer provides `checked`, `onChange` and `label` (accessible name; the visible label lives in the SettingsRow). Off: `surface-sunken` track with an `edge` border and an `edge` knob (3:1 in both themes). On: `vine` (chartreuse) track with a `vine-ink` edge and an `on-vine` knob.
