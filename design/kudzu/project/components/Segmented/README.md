# Segmented

A two-to-four option switch for mutually exclusive modes ("Inherit from group" / "Custom", "System" / "Light" / "Dark").

Consumer provides `options` (strings or `{value,label}`), optional `value`, `onChange` and `label` (accessible name). The track is `surface-sunken`; the chosen option is a `surface-raised` tab with `shadow-control` and a `line` edge. Accent color never fills a segment.
