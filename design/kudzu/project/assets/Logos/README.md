App icon and menu bar icons for Kudzu.

- `kudzu-app-icon.svg`: the app icon, full colour, 1024 canvas with the macOS squircle. Source of truth.
- `kudzu-app-icon-1024.png`: dithered 1024 render of the app icon, for pages, decks and mockups.
- `kudzu-menubar.svg`: menu bar template glyph (active), 18pt, ink #000 on transparent; macOS recolours it.
- `kudzu-menubar-paused.svg`: same glyph with an outlined leaf, for the paused state. Ink #000.
