# Library parity

Source: `apps/desktop/components/app/main/` for the library window. Native primitives replace the web chrome (§1): `NavigationSplitView`, sidebar `List`, snippet `List`, `Menu`, `.sheet`, `Transferable`. `LibraryScreen` is `LibraryRootView`. T12 hosts it; this feature does not edit `RootView`.

- `main-app.tsx` — source-reviewed; cross-feature focus still needs integration QA. Toolbar, sidebar, list and editor slot, or the Insights / Clipboard / Settings slot. Onboarding replaces the chrome and keeps the Dev badge, command menu, shortcuts, group settings and toaster. A ready update toasts once per version outside Settings (Restart, What's new). ⌘K, ⌘N, ⌘⇧N, ⌘F, ⌘L, ⌘E, ⌘1–5, ⌘,, ⌘/ (and ? outside text editing), ⌘⇧P, ⌘D, ⌘⇧F, ⌘⇧E and ⌘⌫ are window shortcuts. ⌘⌫ leaves native text editing alone. ⌘⇧N creates without inline rename; the sidebar + still starts rename. Escape from the editor remains the editor/host’s integration responsibility; this view does not intercept it, and end-to-end return-to-list focus is unproven. A shortcut whose web `enabled` flag is false still owns the key.
- `sidebar.tsx` — source-reviewed; rename gestures corrected, visual parity incomplete. Snippets and Clipboard disclosure groups remember collapse in `kudzu-sidebar-sections`. Group collapse lasts for the session. Counts, clipboard filters (History always, Pinned always, other kinds when occupied or active), Insights, Settings, context menus, inline rename, drag of groups and snippets. The column is a resizable sidebar (208–280 pt, ideal 224), not a fixed-width div. Move-to-group menus show the full path joined with “ › ” because a native `Menu` does not indent. F2, Option-Return, double-click and the Rename menu item start inline rename. Native key delivery still needs live QA. The brand icon remains a blue K placeholder rather than the bundled app artwork; this visual-only gap remains open and needs a rendering check.
- `snippet-list.tsx` — source-reviewed for scope, sort, filter, empty copy, “Create it”, multi-select, J/K, Home/End, Page Up/Down (±8), ⌘A, Enter, type-to-filter and the bulk bar. The list is a native `List` (tint iris) instead of a 64 px virtualizer; row content is 60 pt inside that row. Selection highlight is the system selection. Type-to-filter appends the typed character and then focuses the field, because a handled key does not also land in the field. ↑/↓ from the filter preserves filter focus. Nested-snippet summaries resolve persisted lowercase UUIDs. Programmatic selection reveal/scroll and native modifier selection still need live QA. Drag out is `LibraryDrag` (`sh.saeed.kudzu.library-item`); T12 declares that UTI.
- `toolbar.tsx` — matched. Sidebar toggle, breadcrumbs, Search… (⌘K). The leading inset is 88 pt on macOS and drops in fullscreen.
- `status.tsx` — source-reviewed; blank Secure Input owners now use the generic explanation. Expanding / Paused / Limited / Needs permission / Secure Input, shield, click-through for blocked and limited, pause button. Health order is the web's: pause, then the web preview, then Secure Input, then permissions.
- `command-menu.tsx` — corrected. `LibraryCommandRows` applies `SearchIndex` once to snippet hits (5 for an empty raw query, 8 otherwise) and requires every whitespace token for actions across label and keywords. Group rows remain hidden for an empty trimmed query. Snippet hits stay first, followed by Selected snippet / Actions / Go to in catalogue order. A feature-local native field and `List` replace the shared design command list’s incompatible second fuzzy filter; rows show group paths and trigger chips, deletion is destructive, and arrow navigation wraps. Import/export still run 250 ms after dismissal. Pure results/navigation are tested; native focus, sheet dismissal and panels need live QA.
- `shortcuts.tsx` — corrected. The five sections and palette / clipboard accelerators remain in a sheet. Content now uses a native `ScrollView`, bounded to min(640 pt, 75% of the parent window height), matching the web’s sizing rule. The bound is tested at short, normal and tall window heights. The sheet uses the popover colour rather than `DialogLayout`, which always draws a footer. Actual short-window rendering still needs native QA.
- `group-settings.tsx` — source-reviewed fields; app-picker integration pending. Name, On/Off, Default / Type / Paste, All apps / Only in… / Except…, and an app-picker slot. `LibrarySlots.groupAppPicker` now supplies the view through a closure; Library no longer references Editor’s concrete `AppPicker`. The host must inject that closure, otherwise the slot is a placeholder (not feature parity). Its live rule binding is tested. A blank name keeps the previous name. Saving calls `saveGroup`.
- `data-actions.ts` — matched as entry points. Open and save panels call the model; interchange stays in the backend. The browser-only “works in the desktop app” toasts are omitted.
