# Settings, Insights, Onboarding, Permissions parity — T11

Sources: `apps/desktop/components/app/main/{settings,insights,onboarding,shortcuts}.tsx`, `apps/desktop/components/app/permissions/*`, `apps/desktop/docs/PERMISSIONS.md`.

Public roots: `SettingsScreen` (`SettingsView`), `InsightsScreen` (`InsightsView`), `OnboardingScreen` (`OnboardingView`), `PermissionCenterView`, `PermissionSetupView`. Hosted by the shell; this task does not edit `RootView` or `PermissionsRootView`.

Native on purpose, matching MIGRATION.md §1: settings detail is a `Form` with `.kzForm()`, switches and segmented pickers; confirmations are sheets; the section list is a vertical stack of buttons with `selectionPill` and SF Symbol icons, not the web's lucide buttons. Reduce Motion goes through `.rise()`, `.checkIn()` and `.kz.springSoft()`.

- `settings.tsx` `SettingsView` — matched as `SettingsScreen`. Eight pages: the web's seven, plus Shortcuts before About. ↑ and ↓ move the section (the web's ArrowUp/ArrowDown). `[` and `]` do the same when a text field is not first responder; the footer only advertises ↑ ↓. The web list has no Shortcuts page because that cheat sheet is only a dialog.
- `settings.tsx` `Group` — matched as `SettingsCardGroup`. The title and the optional description sit above the card; the rows are inside it.
- `settings.tsx` `Row` — matched as KudzuDesign `SettingsRow`.
- `settings.tsx` `HotkeyRecorder` — matched. Click, press a combo, Esc cancels. It shows "Press shortcut…" while recording, and its spoken label is the web `aria-label` (`HotkeyRecorderLogic.accessibilityLabel`). Native addition: bare keys and unusable key codes show a short reason under the recorder; the web ignores them silently. Registration goes through `setPaletteHotkey(accelerator:)` / `setClipboardHotkey(accelerator:)` and `Keys`. Toasts: "Shortcut updated" and "That shortcut is taken".
- Switches in settings rows hide their own label (`.labelsHidden()`); the row title is the label, as in the web where the switch has none.
- The page header is the section label alone (`SettingsNav.header`), as in the web header bar. No subtitles.
- `settings.tsx` `General` — matched. Permissions card only when the platform is macOS or web. Quick-search hotkey. iCloud. Appearance Dark/Light/System via `ThemeSwitch`. Open at login. Dock row hidden on Windows and Linux.
- `settings.tsx` `Expansion` — matched. Pause writes both `Settings.paused` and `EngineStatus.paused`. Prefix is capped at 4. Automatic/Type/Paste. "Good to know".
- `settings.tsx` `ClipboardSettings` — matched. Retention presets and custom days (1…3650, rounded); the days field sits before the picker. "Clear history…" is a secondary button. Paste as plain text. Show secrets plus the ignored-app picker. Clear history confirms in a sheet and always calls clear with pinned items kept (`includePinned: false`).
- `settings.tsx` `copyText` — matched by the agents page copy buttons, which toast through KudzuDesign `toast`.
- `settings.tsx` `CopyBlock` — matched on the AI agents page (command and JSON config): a well with an icon copy button inside, labelled `Copy {label}`, toasting `Copied {label}` or "Couldn’t copy".
- `settings.tsx` `Agents` — matched. `agentAccess`, `agentWrite`, `agentClipboard`, secrets card. "Connect an agent" is always shown with its description; in order: Claude Code and the command, the skill row, then Other apps, the config and the bundled skill note. The copy blocks wait for setup. The skill button shows while setup loads but stays disabled (`AgentCopy.skillButtonDisabled`), keeps its label beside a spinner while installing, and reloads setup either way ("Skill installed" / "Couldn't install the skill").
- `settings.tsx` `Apps` — matched. "Never expand in" and "How to insert, per app", with the web descriptions. Adding an app defaults that app to paste and does not overwrite an existing method. Per-app control is a segmented Auto/Type/Paste. Remove is labelled `Remove {name}`.
- `settings.tsx` `Data` — matched. Import and export call `DataActions` (Raycast, TextExpander, Kudzu or Espanso file, Espanso folder, JSON and YAML). Detected Espanso imports through the model and toasts `Imported {n} snippets` or "Import failed". Backups list the last 14, reason and relative time, with no snippet count (`BackupInfo` has none). "Back up now" toasts "Backup saved". "Show data folder" reveals the directory. Restore is a sheet ("Restore backup?") that then calls `restoreBackup`; the web restores on the button press with no confirm. The sheet is the native dialog from §1.
- `settings.tsx` `ICloudSync` — matched (`SyncLine`). One row: "Sync with iCloud" with the status line as its description, then the trailing action (`SyncLine.action`: "Update", which jumps to About, or "Sync now" on up to date and error) and then the unlabelled switch. The intro text is the group description. Off, unavailable, no account, starting/syncing, up to date, needs update, and error.
- `settings.tsx` `About` — matched. App icon, small wordmark, "Version x · MIT licensed", tagline and description. Updates are always shown (the web page does not gate them). Privacy is the one brand paragraph with the shield, not a second title and not "Run setup again".
- `settings.tsx` `UpdateRow` — matched. Checking, up to date, downloading (bar, 30% when the total is unknown), ready ("Downloaded and verified…", "Restart to update", parsed notes, "All release notes"), restarting ("Installing… Kudzu will reopen by itself."), and error. `needsMove` is a warning line plus "Check now"; there is no separate "Move to Applications" button. Checking shows a spinner beside "Check now". Failure toast: "Couldn’t install the update". Beta is a switch on `updateChannel`.

- `insights.tsx` `Insights` — matched as `InsightsScreen`. Header bar, four tiles, top 10 by count (ties keep library order, like the web's stable sort), six recent by last use (ties keep ranking order), unused enabled snippets that have a trigger and no count (18 shown), typing-speed slider 10–150 step 5 bound to `typingSpeedWPM`, footer lock line. Opening a row sets the library to All and selects it. Usage is `SnippetUsage`, not fields on `Snippet`.
- `insights.tsx` `Tile` — matched inside that screen: Expansions, Characters saved, Time saved, Active snippets. Counts and durations go through `Stats.formatCount` and `Stats.formatDuration`. Bars use KudzuDesign `InsightBar`.

- `onboarding.tsx` `Onboarding` — matched as `OnboardingScreen`. Welcome (wordmark, tagline, description, `;sig` example, Get started, "A few small steps…"), then Access only on macOS and web, then Import, then Try it. No "Skip setup" and no "Continue without expanding (paused)". Back from any step after welcome. Skip for now advances; it does not finish onboarding paused. Continue on Access stays disabled until expansion is ready. The stepper is a progress list, not a row of jump buttons. Finish sets `onboardingCompleted` and shows "We couldn’t finish setup…" on error. Atmosphere is the iris radial wash; Reduce Motion skips the step spring.
- `onboarding.tsx` `newSnippets` — matched as `OnboardingLogic.newSnippetCount`: imported snippets minus dedupe merges, never below zero. That count chooses Continue versus Skip.
- `onboarding.tsx` `SourceRow` — matched. Espanso looks on this Mac, then Import or Choose folder. Raycast and TextExpander use `DataActions.pickImportFile` and `backend.importFile`. Outcomes show the new-snippet count and the first warning. A failed detected folder reports every folder imported so far, earlier attempts included (`OnboardingLogic.espansoFailure`). Parsers stay in the backend.
- `onboarding.tsx` `Practice` — matched. A trailing `;kudzu` (any case) becomes `Hello from Kudzu!` with no extra space. Success is that string contained in the field. The desktop copy is "When expansion is enabled, your library’s triggers work in Notes, Mail, your browser, and other apps."; the web-preview line only shows on `.web`. The palette shortcut is the live `paletteHotkey`.

- `shortcuts.tsx` `ShortcutsDialog` — matched as `ShortcutsDialogView` (720 pt sheet, "Every shortcut in Kudzu.", live search and clipboard accelerators, Done). The same catalog and accelerator line are also the Shortcuts settings page. The web has the dialog only. The catalog is `ShortcutsCatalog` and `Keys`.

- `permission-setup.tsx` `permissionsReady` — matched as `PermissionsLogic.isReady`: accessibility, `canPostEvents`, and the tap not off.
- `permission-setup.tsx` `PermissionSetup` — matched as `PermissionSetupView`. Shield, "Permissions are set" / "Enable typing in other apps", the two rows, full-width "Set up permissions" / "Review permissions" / "Opening…". It calls `showPermissions()` and shows a local error. It does not open the setup window itself.

- `permission-center.tsx` `PermissionCenter` — matched as `PermissionCenterView`. Headlines "You’re all set." / "Access is allowed." / "Let Kudzu do the typing." Needs-connection is only the accessibility row when it is granted and expansion is not ready. Restart is offered after 5 seconds. No auto-advance. Primary button: "Back to Kudzu", "Restart {app}", "Set up app control", or "Open System Settings" / "Opening Settings…". Escape closes help, then the companion. The accessibility label comes from `permissionContext().accessibilityName`. The icon reports its screen bounds to `installPermissionIcon`. Reduce Motion skips the help transition. Backend failures (context, status poll, icon, close, reveal, restart, stop guide) show in the handoff error area, like the web's `fail`. The hero is `NSApp.applicationIconImage`, with the small wordmark if the process has no icon. The hosted review captures show a generic folder because that renderer is not the Kudzu app bundle.
- `permission-center.tsx` `PermissionPreview` — not ported. Those six buttons only dispatch `kudzu:preview-permission` in the browser. `MockBackend.previewPermission` still exists for previews.
