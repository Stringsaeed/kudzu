## 7. Ambiguities and existing gaps

- **Explicit insertion versus disabled/rules copy:** editor says turned-off snippets “won't expand,” but Quick Search uses explicit guard and only global exclusions, not snippet/group enabled or allow/deny eligibility. Decide whether to preserve that exception or explicitly fix it; do not accidentally impose matcher eligibility. `components/app/editor/snippet-editor.tsx:336`, `src-tauri/crates/kudzu-engine/src/macos/engine.rs:1117`.
- **Permission health indicators differ:** companion uses Accessibility+post+listener; engine canExpand uses listener+post+pause/Secure Input; sidebar `health` and tray summary omit posting check and can display Expanding/Ready too broadly. Source contract is permission companion/engine fields; decide visible wording parity. `components/app/permissions/permission-setup.tsx:10`, `src-tauri/crates/kudzu-engine/src/status.rs:19`, `components/app/main/status.tsx:17`, `src-tauri/src/tray.rs:129`.
- **Onboarding starter text differs:** practice outputs “Hello from Kudzu!”, core seeded `;kudzu` outputs “Kudzu is working!”. Practice is UI substitution and cannot establish permission/live expansion. `components/app/main/onboarding.tsx:25`, `src-tauri/crates/kudzu-core/src/interchange/coordinator.rs:22`.
- **Clipboard cap wording:** README says up to5000 items; core counts5000 unpinned plus unlimited pinned. Pruning is periodic/settings-triggered, not each ingest, so temporary over-cap histories are possible. `src-tauri/crates/kudzu-core/src/clipboard.rs:594`, `src-tauri/src/clipboard/mod.rs:76`.
- **Text filter comment differs from code:** `lib/clipboard.ts` comment says Text covers code/other, implementation includes text/other only. Picker omits Code/Colors filter buttons but query is:code/is:color works. No user-created clipboard-folder CRUD exists; folders mean kind filters. `lib/clipboard.ts:132`, `components/app/clipboard/clipboard-picker.tsx:25`.
- **Undo guarantees differ:** snippet delete Undo restores records but already-pruned form memory is lost; group delete lacks undo; clipboard Undo can recover blobs only until next launch and restore skips duplicate hashes. The bulk “Turn off all” accessible label actually toggles each item. `src-tauri/src/commands.rs:120`, `components/app/main/sidebar.tsx:418`, `src-tauri/src/clipboard/store.rs:88`, `components/app/main/snippet-list.tsx:592`.
- **Editor failure recovery incomplete:** flush clears dirty before async save, no retry dirty restoration; optimistic store mutations lack rollback; external updates can arrive while save is in flight. Source-only parity must not imply safe recovery already works. `components/app/editor/snippet-editor.tsx:73`, `lib/store.ts:213`.
- **Group Save dismisses immediately:** save promise not awaited, duplicate-submit/error recovery absent; Cancel/Escape close local draft. No proven pending-save race handling. `components/app/main/group-settings.tsx:35`.
- **Disk success is weaker than API success:** store saves log errors instead of returning them; corruption rename is best-effort, fixed `.tmp` path used; settings/form decode failures silently default. README “corrupt library never overwritten” assumes rename succeeds. Rune migration must distinguish claimed preservation from current failure behavior. `src-tauri/src/store.rs:27`, `src-tauri/src/store.rs:93`, `src-tauri/src/store.rs:140`.
- **Backup14 is not an immediate universal invariant:** daily/manual prune, import/restore/version backup call sites do not uniformly prune immediately; UI lists only 14. PreUpdate backup occurs after Store::load, not before any future loader migration. `src-tauri/src/store.rs:192`, `src-tauri/crates/kudzu-core/src/interchange/coordinator.rs`, `components/app/main/settings.tsx:734`.
