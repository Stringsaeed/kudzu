- Rune workaround: selection pills are scoped to their scroll/fold containers so they track live row geometry. The pill fades between sections or group rows rather than gliding across them. This intentional difference is recorded in `PARITY_MATRIX.md`. No upstream issue was filed, per the brief.
- Test-first process: navigation, menu, rename, drag/drop, clipboard updates, IME, error and motion slices were driven by observed failing tests. Some supplemental checks, including subgroup creation, destructive deletion, Option-Return, blank rename, self-drop and some status/motion copy, were added after their behavior existed; strict red-first was therefore not demonstrated for every individual assertion.
- Earlier test runs used pre-existing scratch helpers with hard-coded system temporary paths before the retro's worktree-only rule was available. Subsequent scratch helpers use `std::env::temp_dir()` and final commands use a worktree-local `TMPDIR`. The assembly helper makes that path relative to the working directory to keep Unix socket paths short.
